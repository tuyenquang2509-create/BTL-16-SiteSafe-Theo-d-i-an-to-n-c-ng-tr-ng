# Roles and Features

## Worker
- Thực hiện checklist.
- Báo hazard.
- Xem/sửa/quản lý hazard của mình.

## Safety Officer
- Review hazard.
- Xem dashboard.
- Quản lý inspection.
- Giao corrective action.

## Site Manager
- Theo dõi hotspot.
- Theo dõi corrective action.
- Xem safety report.

## Admin
- Quản lý checklist template.
- Quản lý zone.
- Quản lý user.
