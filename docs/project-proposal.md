# Project Proposal

## Tên
SiteSafe – Theo dõi an toàn công trường

## Lĩnh vực
ConstructionTech

## Vấn đề
- Checklist không đồng nhất.
- Hazard thiếu workflow theo dõi.
- Ảnh minh chứng khó gắn với lịch sử.
- Quản lý thiếu hotspot/heatmap rủi ro.

## Mục tiêu
Xây dựng frontend prototype có nhiều vai trò, CRUD có ý nghĩa, responsive, JavaScript, dữ liệu giả lập và 3 trải nghiệm AI.

## User flow
Khám phá/đăng nhập → nghiệp vụ theo vai trò → xem trạng thái/dữ liệu → AI hỗ trợ → chấp nhận/sửa/từ chối/lưu → xử lý vận hành → dashboard/báo cáo.
