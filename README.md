# SiteSafe – Theo dõi an toàn công trường

Prototype frontend dùng HTML5, CSS3 và JavaScript thuần.

## Chạy dự án
1. Giải nén `SiteSafe_Web.zip`.
2. Mở thư mục trong VS Code.
3. Mở `index.html` trực tiếp hoặc chạy bằng extension Live Server.

## Chức năng demo
- Dashboard tổng quan, chỉ số, biểu đồ và nguy cơ ưu tiên.
- Danh sách nguy cơ: tìm kiếm, lọc, xem chi tiết, thêm/sửa/xóa.
- Lịch kiểm tra dạng tuần, thêm/sửa/xóa lịch.
- Hành động khắc phục, khu vực công trường, mẫu checklist và người dùng.
- Báo cáo an toàn và xuất CSV.
- Trợ lý AI mô phỏng: phân loại nguy cơ, tạo checklist, phân tích điểm nóng.
- Responsive cho màn hình nhỏ; dữ liệu lưu trên trình duyệt bằng localStorage.

## Lưu ý
Đây là prototype frontend với dữ liệu mẫu. Chưa có backend, cơ sở dữ liệu dùng chung, đăng nhập thật hoặc mô hình AI thực tế. Các gợi ý AI là mô phỏng để trình diễn luồng giao diện.
